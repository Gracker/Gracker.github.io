Perfetto Series

Perfetto has become my main tool for everyday Android performance analysis. Readers new to performance work have told me that its busy interface and many features leave them overwhelmed. They asked me to revisit the Systrace articles using Perfetto, so that is what I’m doing in this series.

Tools and versions — updated October 13, 2026: Systrace belongs to the legacy workflow. Android’s System Tracing utility saves Perfetto-format data on Android 10 (API 29) and later; use Perfetto UI and Trace Processor as the primary analysis path. See Android system tracing. Supported legacy Systrace data can also be imported; legacy-viewer availability and compatibility depend on the viewer version. Older thread-state, Vsync, Input, SurfaceFlinger, and Binder articles remain useful learning references, but their functions, timing, and limits must be read against each article’s Android version.

Systrace Series

The Systrace tool is a powerful tool for analyzing Android performance issues. It can show the operation of the entire machine from a graphical perspective. The Systrace tool can not only analyze performance issues but is also excellent for learning the Framework, which is one reason I wrote this series.

Public Projects

Android Internals Wiki (AIW)

Android Internals Wiki contains Android Internals: System Architecture, Performance & Tooling in Practice. Its five parts and 26 chapters cover system mechanisms, performance, tools, platform/OEM work, and App practices. The current README names Android 17 / API 37 as its baseline; device behavior still requires version-specific checks. The full text is currently Chinese, with an English navigation summary.

  • Open-source introduction.
  • Web edition and complete contents.
  • EPUB releases.
  • Contributing: include the Android version, source location, and reproducible observation when reporting an error.

SmartPerfetto

SmartPerfetto was the open-source project I was spending the most time on when I put this list together. It adds an AI Assistant to Perfetto. Questions about a loaded trace lead to evidence gathered through trace_processor_shell, SQL, YAML Skills, and scenario strategies. Results remain limited by the captured data; AI interpretation does not replace source inspection, queries, or reproduction.

  • Perfetto UI fork hosting the Assistant integration.
  • A TypeScript backend for agent execution, tools, Skills, reports, and streaming output.
  • YAML Skills and Markdown strategies for startup, scrolling, ANR, Binder, CPU, memory, and rendering.
  • Introduction, architecture, and architecture Q&A.

Android App Memory Analysis

Android-App-Memory-Analysis brings dumpsys meminfo, dumpsys gfxinfo, HPROF, and smaps into a common investigation.

  • Collect available data from connected devices. HPROF/smaps access depends on debuggability, permissions, and device policy.
  • Correlate Java heap, native, graphics, and process-level evidence, with readable reports.
  • The current README describes Android 17 / API 37 Demo and input-format adaptation, alongside Android 16 and 16 KB page-size notes. A build target or parser claim does not prove validation on every device.

TraceFix

TraceFix inserts paired android.os.Trace.beginSection/endSection calls into App bytecode at build time, reducing manual instrumentation work. Instrumentation also has a cost; bound its scope and compare equivalent runs.

As of October 13, 2026, Maven Central metadata and the POM confirm io.github.gracker:TraceFix:0.1.0. The repository README describes 0.2.x for Android 17 / AGP 9.1.x, but the 0.2.0 POM is not available at that repository endpoint. Distinguish source-branch documentation from published dependencies.

Perfetto Auto-Pin

Perfetto-AutoPin-For-Chrome pins frequently used tracks through presets such as Frame, Startup, Input, Memory, Binder, SurfaceFlinger, SystemUI, and CPU analysis, with custom track sets.

It relies on Perfetto UI internals, so compatibility can change with UI versions. Perfetto’s own commands and macros offer another way to reduce repeated track setup.

High Performance Friends Circle

Friends-Circle-Demo-Apks-For-Power-and-Performance-Test is a Moments-style Android workload suite for startup, scrolling, and App switching. Different UI implementations and loads support investigation of main/RenderThread work, SurfaceFlinger, CPU, frames, and power. A Flutter suite provides related workloads.

Apps in Development

100Years

100Years is an iPhone / Apple Watch App for health trends and long-term health signals. It combines HealthKit, lifestyle, health records, workouts, and sleep data. Deterministic models produce estimates, with optional AI explanations. Lifespan, age-100, and healthy-lifespan outputs are product estimates without external clinical calibration, not personal survival probabilities or medical conclusions.

The source is not publicly linked here. Work continues on data import, health-data synchronization, SwiftUI, localization, and release readiness; this description does not establish a public release.

iBattery

iBattery is a cycling-device battery monitor for iOS, covering compatible Bluetooth sports devices such as power meters, heart-rate sensors, shifting systems, and cadence sensors.

  • Discovers and classifies nearby devices.
  • Updates battery state and alerts when the device exposes readable battery data; discovery alone does not guarantee access.
  • Shows recent readings in iOS Widgets. Widget refresh is not continuous Bluetooth sampling; reading age matters.
  • Includes localization, caching, notifications, and appearance settings.

The iOS repository is not publicly linked here; an Android version is also a local development direction.

Juju

Juju is an Android growth journal I’m making for my family, for recording a child’s age, milestones, and photos, with home-screen widgets. It is not presented as a public open-source release.
