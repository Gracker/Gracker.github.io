SmartPerfetto 的版本更新以后集中写在这一篇，新的记录放在最前面。这里合并了此前几篇更新文章，主要保留版本范围、时间和重要变化。

目前整理到 v1.15.1（2026-10-06）。这是本文覆盖的版本，不代表项目的最新发行版；下载请看 GitHub Releases。

v1.12.0 → v1.15.1｜2026-09-17 至 2026-10-06

这一阶段主要调整源码与知识库的使用方式、答案交付流程，并修复分析口径和安装问题。

  • 源码和文档按轮选择：入口移到输入框旁，可分别选择本轮使用的代码库和知识库；源码支持按需搜索、定位声明和 Trace 标记，并提供不同读取深度。读取预算与发送给 Provider 的授权分别控制。
  • 普通文档文件夹成为知识库：注册、权利确认、建索引和发送授权分开处理。v1.15 移除了内置 Android Internals Wiki Pack 和 smp knowledge-pack，已有用户需要重新注册有权使用的文档目录。
  • 答案先交付，核验随后完成：支持的运行时显示临时流式草稿，最终正文与核验状态分别呈现；草稿不写入历史。五条运行时共用最终交付流程，涉及私有源码或知识库的报告与快照仅创建者可读。
  • 场景分析修正：滑动分析同时看帧耗时与呈现节奏；点击响应区分物理输入、应用投递和候选帧关联；启动、CPU 和点击详情按 UPID 隔离进程实例；堆转储增加类增长、可达实例和支配大小观察。
  • CPU 簇负载修复：统一分子、分母的时钟口径，修复跨休眠区间及多设备 CPU 身份混用。数据无法确认时返回不可用原因和空值。
  • 旧入口清理：停用旧 SQL、模板分析、Wiki API 和 Skill 内的模型调用步骤；移除开发模式绕过认证与归属检查的 /uploads 静态下载入口。迁移前应查看对应版本说明。
  • v1.15.1 安装与测试修复（10-06）：smp doctor --format json 增加原生 SQLite 查询探针；npm 安装检查加入独立消费项目和真实 SQL 查询；相关测试使用各自的临时数据库与目录。
  • v1.12.1（09-21）：此前文章中记为“发布后主分支进展”的磁盘预检、启动 wakeup chain 与 sleep attribution、假设重新求解和提示词预算，已归入这个版本。

旧版实测中，DeepSeek 长报告、OpenCode 启动正文和 OpenAI 滑动声明核验仍有未通过项，不能据这些功能改动认定所有运行时的真实分析都已验收。

详细变更：v1.15.1 Changelog。

v1.7.0 → v1.12.0｜2026-08-21 至 2026-09-17

这段时间包含 v1.8.0、v1.8.1、v1.8.2、v1.8.3、v1.8.4、v1.9.0、v1.10.0、v1.11.0、v1.12.0，主要变化如下。

版本 主要更新
v1.8.x 双 Trace 工作台支持直接上传、替换任意两条 Trace，交换基线与对照并恢复布局；源码分析减少对预建索引的依赖；同步 Perfetto v58.2
v1.9.0 Auto / Fast / Full 成为显式分析模式，后续提问保留模式意图；源码使用来源进入报告
v1.10.0 保存调查检查点，后续轮次可沿用假设、证据和待查项；已授权源码目录无活动索引时也可按需读取
v1.11.0 最终答案的声明绑定本轮工具证据，增加有界语义复核；Web、CLI、HTML 报告和快照保留核验结果；取消 Claude SDK 隐式读取本机 Claude Code 登录的后备路径
v1.12.0 补齐声明格式、传输与重试诊断；滑动背压调查按证据触发；增加系统分析 E2E 场景定义和策略加载诊断 smp probe

检查点用于后续轮次继续调查，不表示后台任务自动续跑；Fast 仍可能调用模型。partial、not_checked 等核验状态保留原含义，不等于完整通过。

详细变更：v1.12.0 Changelog。

v1.1.1 → v1.7.0｜2026-07-17 至 2026-08-21

这一阶段主要补齐三平台交付、大 Trace、源码分析和受控反馈流程。

日期（2026 年） 版本 主要更新
07-18 v1.2.0 签名 Android Internals Knowledge Pack 随发行物交付；这套机制后来在 v1.15 移除
07-18 至 07-28 v1.2.x 中文分析界面、Android Skills 防护、可选 Qoder 运行时、更新通知与三平台发布流程加固
07-28 v1.3.0 大 Trace 双窗使用隔离的 Trace Processor RPC session；增加本机目录选择器
08-03 v1.4.0 Self-Evolution 受控提案、评估与人工应用流程；Agent 辅助生成反馈草稿；默认关闭的企业 OIDC 登录与工作区隔离
08-10 v1.5.0 Code-Aware 源码分析、带来源的报告、Mermaid 加固和 Windows DPAPI 修复；日期按 Changelog
08-14 v1.6.0 Pi 显式 Provider 配置、Windows 数据目录策略、双 Trace 身份与最终报告质量检查
08-21 v1.7.0 Qoder BYOK 路由、DeepSeek / Pi 收尾修正；六份真实 Trace fixture 补齐许可、公开同意和隐私审查记录

同期完善了 macOS 签名与公证、Windows 原生运行检查、发布包摘要和更新提示。更新检查只负责通知；Self-Evolution 的应用与回滚需显式启用和人工操作，反馈入口只生成待审查草稿。

详细变更：v1.7.0 Changelog。

v1.0.28 → v1.1.1｜2026-06-04 至 2026-07-17

这一阶段增加双窗工作台、确定性证据直答、私有分析上下文，并统一四条 Agent 运行时的公共流程。区间起点沿用原文的记录日期；v1.0.28 实际发布于 06-02。

日期（2026 年） 版本 主要更新
06-05 v1.0.29 内存分析证据加固，修正线程阻塞原因的证据语义
06-06 v1.0.30 同步 Perfetto v56.0
06-06 v1.0.31 Agent E2E 验证接入 DeepSeek 真实链路
06-07 v1.0.32 运行时 engine 重组、取消语义贯通、第三方运行时状态续传与误诊模式库
06-07 v1.0.33 免安装包排除运行时数据
06-17 v1.0.34 DeepSeek 分析链路修正与轮次预算调整
06-19 v1.0.35 策略拆成常驻 Core 与按需 Detail，压缩工具描述，大 SQL 结果转摘要与分页引用
06-22 v1.0.36 案例知识平台、自进化 V1 与记忆层修复
06-22 v1.0.37 macOS 免安装包签名资源修复
07-04 v1.0.38 Quick Mode 证据直答和分析回执、Provider preset 更新、Perfetto v57.1
07-11 v1.0.39 双 Trace 工作台与 RFC-0025 的八类 AI 工作流
07-17 v1.1.0 统一运行规格和私有上下文授权；扩展 Camera / Heap / GPU 场景、Android 17 渲染知识、Trace 案例库与公共 Skill 导出；同步 Perfetto v57.2
07-17 v1.1.1 修复 Docker 中 OpenCode 运行时链接与 arm64 构建路径

Quick Mode 只在命中支持的意图且证据可用时做到零轮模型直答。当时的双窗是“当前 Trace + 历史参考 Trace”，任意双 Trace 输入是后续 v1.8.0 的变化；Camera、Heap、GPU 分析仍依赖实际采集的数据源。

详细变更：v1.1.1 Changelog。

v1.0.7 → v1.0.28｜2026-05-17 至 2026-06-04

v1.0.28 发布于 2026-06-02，原更新文章记录到 06-04。

  • Smart 模式：先列出 Trace 中识别到的场景，再选择范围深入分析；场景预览不等于根因分析已经完成。
  • 选区快问与 CLI：时间线选区或事件上下文进入分析请求；smp capture android、终端分析、对比与会话产物复用后端核心。
  • 更多场景证据规则：加强 Power、ANR、Input、Display、IO、Network 与采集完整性检查；失败 SQL 的诊断信息不再作为成功查询证据展示。
  • 四条运行时：Claude、OpenAI、Pi Agent Core、OpenCode 共用工具注册和公共输出规则，继续修复报告完整性、证据来源与会话恢复。

详细变更：v1.0.28 Changelog。

开源后首轮更新｜2026-04-29 至 2026-05-17

原文标题对应 v1.0.7（2026-05-14 发布），正文实际记录到 05-17 的源码快照，包含发布后的主分支变化，不能全部视为 v1.0.7 安装包功能。

  • 增加分析结果快照、相似案例检索与跨窗口结果对比，已完成的结果可以复用。
  • Claude / OpenAI 双运行时、Provider Manager 与运行诊断进入主要使用流程。
  • SQL stdlib 检查、证据 ID、数据来源与逐句引用加入输出，方便从结论回查表格。
  • 渲染管线教学开始关联当前 Trace 的实际事件，并标明缺失信号。
  • 完善 Docker、三平台免安装包、源码和 CLI 分发；修复大文件上传、启动兼容性、会话隔离与前端预构建资产问题。
